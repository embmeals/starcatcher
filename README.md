# Starcatcher

Fly as a little cat alien around a night sky collecting stars and dodging spiked balls.

This repository holds the exported web build only, served by GitHub Pages at
https://starcatcher.emills.net (also https://embmeals.github.io/starcatcher/).
The game source lives in a separate private repository; the build here is
refreshed from it with the deploy script there.

Built with Godot 4.7, models generated in Blender from Python.
